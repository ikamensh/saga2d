### Section 2 — Repro Steps

#### EC1: DataTable(row_height=0) ZeroDivisionError

```python
from saga2d.ui.widgets import DataTable

dt = DataTable(columns=["Name"], rows=[["Alice"]], row_height=0)
dt._computed_x, dt._computed_y = 0, 0
dt._computed_w, dt._computed_h = 200, 100
dt._header_height = 32

class FakeEvent:
    type = "click"; button = "left"; x = 100; y = 40; action = None; dy = 0

dt.on_event(FakeEvent())  # → ZeroDivisionError: integer division by zero
# Location: widgets.py DataTable.on_event() line: int(relative_y // self._row_height)
```

**Fix pattern:** Add `if self._row_height <= 0: return True` guard before the division, matching `List.on_event()`.

#### EC2: MoveTo.update(NaN) corrupts sprite position

```python
from saga2d.actions import MoveTo

action = MoveTo((100, 100), speed=100)
# After action.start(sprite):  sprite at (0,0)
action.update(float('nan'))
# sprite.position → (NaN, NaN) — silently corrupted
```

**Impact:** No production path. Game clock never produces NaN dt. Only reachable via direct `update()` call.

#### EC3–EC5: Component tree mutation during iteration

```python
from saga2d.ui.component import Component

class RemovingSibling(Component):
    def __init__(self, target_ref=None):
        super().__init__()
        self.target = target_ref
    def update(self, dt):
        if self.target and self.parent:
            self.parent.remove(self.target)  # mutates _children mid-iteration

parent = Component()
a, b, c = Component(), RemovingSibling(), Component()
parent.add(a); parent.add(b); parent.add(c)
b.target = c

# _update_recursive(parent, 0.016) walks parent._children = [a, b, c]
# After b.update() removes c, the for-loop may skip c or encounter stale state.
# Same pattern applies to draw() and handle_event().
```

**Fix pattern:** Use `list(component._children)` snapshot in all three iteration sites, matching `TweenManager.update()` / `TimerManager.update()`.
