### Section 2 — Repro Steps

#### EC1: DataTable(row_height=0) ZeroDivisionError

```python
from saga2d.ui.widgets import DataTable

dt = DataTable(columns=["Name"], rows=[["Alice"]], row_height=0)
dt._computed_x, dt._computed_y = 0, 0
dt._computed_w, dt._computed_h = 200, 100
dt._header_height = 32

class FakeEvent:
    type = "click"; button = "left"; x = 100; y = 40; action = None; dy = 0

dt.on_event(FakeEvent())  # → ZeroDivisionError: integer division by zero
# Location: widgets.py DataTable.on_event() line: int(relative_y // self._row_height)
```

**Fix pattern:** Add `if self._row_height <= 0: return True` guard before the division, matching `List.on_event()`.

#### EC2: MoveTo.update(NaN) corrupts sprite position

```python
from saga2d.actions import MoveTo

action = MoveTo((100, 100), speed=100)
# After action.start(sprite):  sprite at (0,0)
action.update(float('nan'))
# sprite.position → (NaN, NaN) — silently corrupted
```

**Impact:** No production path. Game clock never produces NaN dt. Only reachable via direct `update()` call.

#### EC3–EC5: Component tree mutation during iteration

```python
from saga2d.ui.component import Component

class RemovingSibling(Component):
    def __init__(self, target_ref=None):
        super().__init__()
        self.target = target_ref
    def update(self, dt):
        if self.target and self.parent:
            self.parent.remove(self.target)  # mutates _children mid-iteration

parent = Component()
a, b, c = Component(), RemovingSibling(), Component()
parent.add(a); parent.add(b); parent.add(c)
b.target = c

# _update_recursive(parent, 0.016) walks parent._children = [a, b, c]
# After b.update() removes c, the for-loop may skip c or encounter stale state.
# Same pattern applies to draw() and handle_event().
```

**Fix pattern:** Use `list(component._children)` snapshot in all three iteration sites, matching `TweenManager.update()` / `TimerManager.update()`.

### Bugs Reproduced and Fixed

#### F29: Camera.scroll() NaN/Inf silent corruption (uncommitted fix found)

- **Repro:** `Camera.scroll(float('nan'), 0)` silently corrupted internal `_x`/`_y` — all subsequent coordinate conversions produced NaN.
- **Root cause:** `scroll()` lacked `math.isfinite()` guard unlike `center_on()` and `pan_to()`.
- **Fix:** Added `if not math.isfinite(dx) or not math.isfinite(dy): raise ValueError(...)` guard at the top of `scroll()`.
- **Test:** `TestCameraScrollNaNInf` (7 tests) in `tests/test_kodo_camera_drag_edge.py` — all pass.
- **Status:** Fix already present as uncommitted change in `saga2d/rendering/camera.py`.

#### F30: Component tree iteration mutation skips children (EC3/EC4/EC5)

- **Repro:** If a component's `update()`, `on_draw()`, or `on_event()` callback removes a sibling from `_children`, the iterator over the live list silently skips subsequent children. Confirmed all three paths:
  - EC3: `_update_recursive()` — sibling removed during `update()` → next child skipped
  - EC4: `draw()` — sibling removed during `on_draw()` → next child skipped
  - EC5: `handle_event()` — `reversed()` on live list → removed child skipped
- **Root cause:** All three iteration sites iterated over `self._children` / `component._children` directly without snapshotting, unlike `TweenManager.update()` and `TimerManager.update()` which use `list()`.
- **Fix:** Changed all three to iterate over `list(self._children)` / `list(component._children)` snapshots in `saga2d/ui/component.py`:
  - `handle_event()`: `reversed(self._children)` → `reversed(list(self._children))`
  - `draw()`: `for child in self._children` → `for child in list(self._children)`
  - `_update_recursive()`: `for child in component._children` → `for child in list(component._children)`
- **Tests:** `TestComponentMutationNoSkip` (4 tests) in `tests/test_kodo_ui_particle_edge.py` — all pass. These assert children are NOT skipped (stronger than prior "no crash" tests).

### Bugs Reproduced and Fixed

#### F44: ProgressBar constructor NaN/Inf bypass

- **Repro:** `ProgressBar(value=float('nan'), max_value=100)` — constructor stored NaN in `_value` without validation; the setter validated but the constructor bypassed it by assigning directly to `self._value`. On CPython, `min(1.0, NaN)` returns `1.0` so `fraction` appeared to work, but this is platform-dependent and masks a logic error.
- **Root cause:** Constructor assigned `self._value = value` and `self._max_value = max_value` without calling the setter or checking `math.isfinite()`.
- **Fix:** Added `math.isfinite()` validation for both `value` and `max_value` in `__init__()`.
- **File:** `saga2d/ui/widgets.py`
- **Tests:** `TestF44ProgressBarConstructorValidation` (11 tests)

#### F45: Button.text setter accepts None

- **Repro:** `btn.text = None` — accepted silently, then crashed in `_estimate_text_width()` with `TypeError: 'NoneType' object is not iterable`.
- **Root cause:** Setter checked `value != self._text` but never validated type. Unlike `Label.text` which converts None to `""`, Button had no guard.
- **Fix:** Added `if value is None: raise TypeError(...)` guard at the top of the setter.
- **File:** `saga2d/ui/components.py`
- **Tests:** `TestF45ButtonTextNoneGuard` (3 tests)

#### F46: ParticleEmitter.position setter accepts NaN

- **Repro:** `emitter.position = (float('nan'), 0)` — stored NaN silently. Next `burst()` call crashed in `Sprite.__init__()` with `ValueError: Sprite position must be finite`.
- **Root cause:** Position setter did `self._x = float(value[0])` without finiteness check, unlike the constructor which validates speed/direction/lifetime.
- **Fix:** Added `math.isfinite()` validation in the position setter.
- **File:** `saga2d/rendering/particles.py`
- **Tests:** `TestF46ParticleEmitterPositionValidation` (4 tests)

#### F47: AnimationPlayer.update(dt=NaN) silently freezes

- **Repro:** `player.update(float('nan'))` — `self._elapsed += NaN = NaN`, then `NaN >= frame_duration` is False, so the while loop never executes. Animation freezes permanently and never recovers.
- **Root cause:** No `math.isfinite(dt)` guard, unlike Camera.update which had one.
- **Fix:** Added `if not math.isfinite(dt): return None` early return (skip frame, don't corrupt elapsed).
- **File:** `saga2d/animation.py`
- **Tests:** `TestF47AnimationPlayerNaNGuard` (5 tests)

#### F48: Camera.enable_edge_scroll accepts NaN/Inf

- **Repro:** `cam.enable_edge_scroll(margin=float('nan'), speed=float('nan'))` — accepted silently. During update, `mouse_x < NaN` is always False, so edge scroll silently stops working. `speed * NaN` would produce NaN scroll offsets.
- **Root cause:** No `math.isfinite()` validation, unlike `center_on()`, `scroll()`, `shake()`, `pan_to()` which all validated.
- **Fix:** Added `math.isfinite()` validation for both `margin` and `speed`.
- **File:** `saga2d/rendering/camera.py`
- **Tests:** `TestF48CameraEdgeScrollValidation` (5 tests)

#### F49: Camera.enable_key_scroll accepts NaN/Inf

- **Repro:** `cam.enable_key_scroll(speed=float('nan'))` — accepted silently. `NaN * dt = NaN` scroll deltas.
- **Root cause:** Same pattern as F48 — missing `math.isfinite()` guard.
- **Fix:** Added `math.isfinite(speed)` validation.
- **File:** `saga2d/rendering/camera.py`
- **Tests:** `TestF49CameraKeyScrollValidation` (5 tests)

#### F50: Camera.world_bounds accepts NaN and inverted bounds

- **Repro:** `cam.world_bounds = (float('nan'), 0, 800, 600)` — NaN stored, `_clamp()` produces NaN positions via `max(NaN, ...)`. Also `cam.world_bounds = (100, 0, 50, 600)` (left > right) — accepted silently, clamp produces wrong results.
- **Root cause:** Setter just stored the tuple and called `_clamp()` without any validation.
- **Fix:** Added finiteness validation for all 4 values, and structural validation (`left <= right`, `top <= bottom`).
- **File:** `saga2d/rendering/camera.py`
- **Tests:** `TestF50CameraWorldBoundsValidation` (9 tests)

#### F51: Tooltip delay accepts NaN/Inf/negative

- **Repro:** `Tooltip("help", delay=float('nan'))` — accepted; `self._timer >= self._delay` where delay is NaN is always False, so tooltip never appears. `delay=-1` — tooltip shows immediately (arguable, but inconsistent).
- **Root cause:** Constructor stored delay without validation.
- **Fix:** Added `math.isfinite()` and `delay >= 0` validation.
- **File:** `saga2d/ui/widgets.py`
- **Tests:** `TestF51TooltipDelayValidation` (8 tests)

#### F52: Sprite.tint passes NaN through to backend

- **Repro:** `sprite.tint = (float('nan'), 0.5, 0.5)` — `max(0.0, min(1.0, NaN))` evaluates to NaN on most platforms (NaN propagates through min/max). NaN tint passed to `_sync_to_backend()`.
- **Root cause:** Setter only clamped to [0,1] without checking finiteness first.
- **Fix:** Added `math.isfinite()` validation for all 3 components before clamping.
- **File:** `saga2d/rendering/sprite.py`
- **Tests:** `TestF52SpriteTintValidation` (6 tests)

#### F53: Sprite.move_to accepts NaN target

- **Repro:** `sprite.move_to((float('nan'), 0), speed=100)` — `math.hypot(NaN, dy) = NaN`, distance check `NaN < 1e-6` is False, `duration = NaN / speed = NaN`, creating a NaN-duration tween.
- **Root cause:** No finiteness check on target coordinates.
- **Fix:** Added `math.isfinite()` validation for `target_x` and `target_y`.
- **File:** `saga2d/rendering/sprite.py`
- **Tests:** `TestF53SpriteMoveToTargetValidation` (5 tests)

#### F54: DataTable row_height <= 0 accepted silently

- **Repro:** `DataTable(columns=["A"], rows=[["x"]], row_height=-10)` — accepted silently. Negative row_height produced negative preferred height, visual artifacts, and potential layout corruption. Zero row_height led to `ZeroDivisionError` on click events.
- **Root cause:** Constructor stored `row_height` without validation.
- **Fix:** Added `if row_height <= 0: raise ValueError(...)` guard in `__init__()`.
- **File:** `saga2d/ui/widgets.py`
- **Tests:** `TestF54DataTableRowHeightValidation` (5 tests)

#### F55: Grid negative cell_size accepted silently

- **Repro:** `Grid(3, 3, cell_size=(-10, 64))` — accepted silently. Negative dimensions produced negative preferred sizes and potentially negative-dimension draw calls. `_cell_at()` returned None (stride ≤ 0 guard), but the layout was nonsensical.
- **Root cause:** Constructor unpacked `cell_size` without checking for negative values.
- **Fix:** Added `if cw < 0 or ch < 0: raise ValueError(...)` guard in `__init__()`. Zero cell_size remains accepted (degenerate but guarded — `_cell_at` returns None).
- **File:** `saga2d/ui/widgets.py`
- **Tests:** `TestF55GridCellSizeValidation` (7 tests)

#### F56: SaveLoadScreen slot_count <= 0 accepted silently

- **Repro:** `SaveLoadScreen(mode="load", slot_count=0)` — accepted silently. Produced a screen with title and Back button but no slot buttons — functionally useless. `slot_count=-1` similarly produced `range(-1)` = empty list.
- **Root cause:** Constructor stored `slot_count` without validation.
- **Fix:** Added `if slot_count <= 0: raise ValueError(...)` guard in `__init__()`.
- **File:** `saga2d/ui/screens.py`
- **Tests:** `TestF56SaveLoadScreenSlotCountValidation` (5 tests)

### Documented Acceptable Behaviors (Not Bugs)

#### DataTable short col_widths

- **Behavior:** `DataTable(columns=["A","B","C"], col_widths=[100])` — accepted. `on_draw()` uses fallback `cw = col_ws[i] if i < len(col_ws) else 0` so columns beyond the col_widths list get width 0 (text overlaps at same x position).
- **Verdict:** **Acceptable** — deliberate API flexibility. The fallback is explicit in the code. Users can provide partial col_widths to size only the first N columns.
- **Tests:** `TestDataTableShortColWidthsAcceptable` (3 documentation tests)

#### Grid zero cell_size

- **Behavior:** `Grid(3, 3, cell_size=(0, 0))` — accepted. `_cell_at()` guard checks `cell_stride_x <= 0` and returns None. Clicks select nothing. Draw emits zero-dimension rectangles. Preferred size is just spacing + padding.
- **Verdict:** **Acceptable** — degenerate but fully guarded. No crash, no corruption. Zero-size cells are a valid edge case (e.g., dynamically resized grids).
- **Tests:** `TestGridZeroCellSizeAcceptable` (3 documentation tests)
