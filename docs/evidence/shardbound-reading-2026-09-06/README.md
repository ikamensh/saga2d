# Codex reading-size evidence

This is a compact record of the native reading matrix for source content
`f327bdde5ed9d4bd3b5595693d9e1e4ac9fbab23`. It retains six inspected frames,
not every captured page. The [provenance manifest](provenance.json) identifies
the capture command, exact source and artifact hashes, Python/packages and
platform, including the verifier's pre-commit capture timing.

The complete [matrix data](matrix.json) records 108 category traversals,
650 measured pages and 1,422 entry presentations: both reading sizes, three
native window sizes, and earned Censer, paid Observatory and v10 active saves.
The logical canvas remained 1280×800. Native backing dimensions were 2× the
requested window sizes on this macOS Retina host.

Public native input checked Apply/Cancel/restart, retained reading position,
all entries reachable once in order, visible Label bounds and unchanged campaign
snapshots. Screenshots were inspected after the independent text-measurement
cache fix `170d32e`; its native warm/fresh regression also compared exact pixels
in both resize directions.

This evidence covers Codex reading content on the named source/host. It does not
claim global game text scaling, other operating systems, human accessibility
approval or final-candidate release readiness. See [the feature scope and
verification guide](../../eador-reading-size.md).
